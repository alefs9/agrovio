## Título

Así funciona Agrovio
Flujo de cinco pasos

- Se publica la oferta
  El proveedor registra el producto, volumen, ubicación, condición y disponibilidad.
- El mercado la descubre
  Los compradores pueden explorar y filtrar todas las ofertas disponibles.
- Comienza la negociación
  El comprador presenta una propuesta y el proveedor puede aceptar, rechazar o
  contraofertar.
- Se alcanza un acuerdo
  Ambas partes definen precio, volumen y condiciones principales.
- Se habilita la conexión
  El comprador utiliza un crédito de conexión para desbloquear los datos del proveedor y
  continuar con el cierre de la operación.

- Preguntas frecuentes
  ¿Necesito ser una empresa para usar Agrovio?
  Agrovio está pensado para distintos participantes del mercado, desde productores hasta
  empresas agroindustriales y compradores institucionales.
  ¿Los compradores pueden ver quién publica un producto?
  No inicialmente. La información comercial es visible, pero los datos de contacto permanecen
  protegidos durante la negociación.
  ¿Enviar una oferta consume un crédito?
  No. El crédito se utiliza cuando el comprador decide desbloquear al proveedor.
  ¿Los proveedores tienen que usar WhatsApp?
  No. Los proveedores pueden utilizar directamente la plataforma. WhatsApp funciona como
  una vía asistida para pequeños agricultores que necesitan una experiencia más sencilla.

¿Puedo actualizar una publicación?
Sí. El proveedor puede actualizar información como precio, volumen y disponibilidad.
¿Qué pasa si una negociación no llega a un acuerdo?
La negociación puede cerrarse sin realizar una conexión comercial.
